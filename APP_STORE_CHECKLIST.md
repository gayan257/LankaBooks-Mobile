# Publish to Google Play and Apple App Store

This checklist covers the launch steps for your LankaBooks mobile app.

## 1. Prepare the app
- Confirm the MVP is stable
- Test on Android emulator and iPhone simulator
- Fix all critical bugs
- Add app icon and splash screen
- Finalize design and branding

## 2. Create accounts
- Google Play Console account
- Apple Developer Program account
- Enable app signing and certificates

## 3. Prepare store assets
### Required assets
- App icon
- Feature graphic
- Screenshots (minimum 2, recommended 6)
- App description
- Privacy policy URL
- Terms and conditions
- Support email

### Suggested app listing
Title: LankaBooks
Short description: Read, write, publish, and buy Sinhala books.
Long description: A community-based reading and publishing app for Sinhala stories, novels, and digital books.

## 4. Build configuration
- Set package/app ID
- Configure version and build number
- Sign release builds
- Ensure proper permissions are declared

## 5. App store submission
### Google Play
- Upload AAB file
- Add app details and screenshots
- Set content rating
- Enter privacy policy URL
- Submit for review

### Apple App Store
- Upload build through Xcode / Transporter
- Add screenshots and app details
- Provide privacy policy and support URL
- Submit for App Review

## 6. Safety and compliance
- Privacy policy page
- Data handling explanation
- Age rating
- Payment policy for purchases
- Content moderation for published books

## 7. Launch plan
- Internal alpha
- Closed beta
- Open beta
- Public launch

## 8. Post-launch
- Monitor crashes and reviews
- Add improvements based on user feedback
- Expand features such as author verification and subscriptions

## 9. Recommended next features
- Book reader with page-turning UI
- Author verification system
- Follow/favorite authors
- Rating and review system
- Payment gateway integration (PayHere / Stripe)
- Push notifications for new releases
