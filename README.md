# LankaBooks Mobile

A mobile app for Sinhala readers, authors, and book buyers. This repo is the initial step in building the MVP for a Wattpad-like reading and publishing platform focused on Sri Lankan books.

## Stack
- React Native + Expo
- TypeScript
- Firebase (planned)
- Stripe / PayHere integration (planned)

## Step 1: Project Setup
This repository currently contains the base app structure and initial landing screen for the platform.

## Features in MVP
- Browse books
- Read books
- Publish/upload books
- Buy books
- Search and filter
- User profile

## Run locally
1. Install dependencies:
   npm install
2. Start Expo:
   npm start
3. Run on a device or emulator:
   - Android: npm run android
   - iOS: npm run ios

## Folder structure
- App.tsx - root app entry
- src/screens/HomeScreen.tsx - main home screen
- src/data/mockBooks.ts - example book data
- src/theme/colors.ts - app colors
